How to turn this into a Gmail template

  1. Open this file in a browser.
  2. Select the email below (from the yellow bar through the footer), copy it.
  3. Gmail → Compose → paste.
  4. Gmail will keep Re: … on a reply. The body now starts with the real subject so it still shows.
  5. If you already saved a template, overwrite it: three dots → Templates → Save draft as template → Save over existing → UNSLOP.
